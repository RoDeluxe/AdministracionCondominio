# 🏢 AdministracionCondominio
![C#](https://img.shields.io/badge/C%23-239120?style=flat&logo=csharp&logoColor=white)
![Windows Forms](https://img.shields.io/badge/Windows%20Forms-0078D4?style=flat&logoColor=white)

Aplicación de **escritorio para la administración de un condominio**, con interfaz gráfica Windows Forms (C#).

## ✨ Módulos
| Formulario | Función |
|---|---|
| `FormApartament` | Gestión de apartamentos |
| `FormCuota` | Gestión de cuotas |
| `FormPago` | Registro de pagos |

## 🔧 Cómo correrlo
Necesita **Windows** con .NET Framework y Visual Studio:

```
git clone https://github.com/RoDeluxe/AdministracionCondominio.git
# abre AdministracionCondominio.sln con Visual Studio
# compila (Ctrl+Shift+B) y ejecuta (F5)
```

## 🗂 Estructura
```
*.csproj / *.sln      solution del proyecto
Form*.cs / *.resx     ventanas del sistema (apartamentos, cuotas, pagos)
App.config            configuración
```
